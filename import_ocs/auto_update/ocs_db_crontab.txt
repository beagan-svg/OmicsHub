# ---- Scheduling Pattern Explanation ----
# The crontab format has 5 fields: minute hour day month weekday
#
# For study.json every 2 hours:
#   0 */2 * * *
#   │  │   │ │ │
#   │  │   │ │ └─ Day of week (0-7, where 0 and 7 are Sunday)
#   │  │   │ └─── Month (1-12)
#   │  │   └───── Day of month (1-31)
#   │  └───────── Hour (*/2 means every 2 hours: 0, 2, 4, ..., 22)
#   └────────────── Minute (0-59)
#
# For vendor data daily at 1 AM:
#   0 1 * * *
#   │ │ │ │ │
#   │ │ │ │ └─ Day of week (any day)
#   │ │ │ └─── Month (any month)
#   │ │ └───── Day of month (any day)
#   │ └───────── Hour (1 AM)
#   └────────────── Minute (0)
