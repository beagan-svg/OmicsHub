{% comment %} One textarea, not three fields: pasted as the literal `export AWS_...=...` block AWS's own SSO/CLI output gives you. job-log-credentials.js parses the three values out of it client-side and posts them under the same three field names the view has always expected -- no server-side change. The textarea is visually masked (-webkit-text-security, see app.css) since the pasted block carries the secret key and session token, not just the non-sensitive access key; Firefox does not support that property and falls back to showing the pasted text in plain view while it's still in the box, same as it would for a native password field pasted into blindly. Only the textarea lives inside the form: the Clear button and status pill are siblings/elsewhere, so hiding the form once credentials are valid (job-log-credentials.js) hides only the paste box -- an ancestor's `hidden` removes its whole subtree from rendering. {% endcomment %}
